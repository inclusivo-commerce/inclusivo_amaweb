# Resultado da análise estática de acessibilidade

O arquivo [eslint.json](eslint.json) contém a saída do ESLint com as regras de acessibilidade do `eslint-plugin-jsx-a11y`, aplicado ao código do frontend da Inclusivo na avaliação de 12/11/2026 (commit `3885b171`). Foram analisados 488 arquivos, com 50 avisos e nenhum erro.

Cada entrada identifica um arquivo em `filePath`. O campo `messages` reúne os achados, com a regra, a mensagem e a posição no código. Os caminhos são relativos à raiz do projeto Inclusivo. Apenas esses caminhos foram adaptados para publicação.

Os avisos indicam trechos do código que merecem revisão. A interpretação de seu impacto na interface depende da avaliação do componente em uso.
